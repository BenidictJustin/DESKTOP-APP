# DommUnity System Beta Testing Evaluation Instrument

---

## 1. Overview

This document presents the **Beta Testing Evaluation Questionnaire** for the **DommUnity System**. Beta testing gathers user feedback from target stakeholders, including **CES Administrators**, **Office Coordinators**, and faculty users, to evaluate the system across content quality, module functionality, multimedia presentation, navigation flow, and overall usefulness.

### Rating Scale

| Scale | Rating | Description |
| :---: | :--- | :--- |
| **1** | **Strongly Disagree** | The feature or aspect completely fails to meet user expectations. |
| **2** | **Somewhat Disagree** | The feature or aspect mostly fails to meet expectations with notable shortcomings. |
| **3** | **Disagree** | The feature or aspect does not adequately meet expectations. |
| **4** | **Agree** | The feature or aspect adequately meets user expectations. |
| **5** | **Somewhat Agree** | The feature or aspect meets expectations with minor room for improvement. |
| **6** | **Strongly Agree** | The feature or aspect fully satisfies and exceeds user expectations. |
